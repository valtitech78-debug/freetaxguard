# TaxGuard 2026 — Free 1099 Tax Calculator

The smartest free tax calculator for 1099 freelancers and independent contractors.

## Features

- 🧮 **AI 1099 Calculator** — SE tax, all 50 states, 2026 IRS brackets
- ⚖️ **W-2 vs 1099 Comparator** — real after-tax difference
- 🎯 **By Profession** — Uber driver, developer, designer, Airbnb host, and 7 more

- ❓ **FAQ** — 12 common 1099 tax questions answered
- 📚 **Tax Guides** — 6 in-depth articles on deductions, QBI, SEP-IRA and more

## Tech Stack

- Pure HTML/CSS/JavaScript — zero frameworks, zero dependencies
- All calculations run locally in the browser (100% private)
- Single file deployment (`index.html`)

## Deploy on GitHub Pages

1. Fork or clone this repo
2. Go to **Settings → Pages**
3. Set source to `main` branch, `/ (root)` folder
4. Your site will be live at `https://yourusername.github.io/repo-name`

## Custom Domain (freetaxguard.com)

Add a `CNAME` file with your domain, then configure DNS:
- A records pointing to GitHub Pages IPs
- Or CNAME record pointing to `yourusername.github.io`
